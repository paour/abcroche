        ABC quick reference
        
      
          
      Header
      
          
      One field per line; X: first, K: last.
      
          
      
            
      T:Title C:Composer
      title, composer
      
            
      M:4/4 M:6/8 M:C M:C|
      time signature (M:none = free)
      
            
      L:1/8
      unit note length: a plain letter lasts this long
      
            
      Q:1/4=120
      tempo
      
            
      K:G K:Am K:Ddor K:Bb clef=bass
      key (last header line); modes and clef too
      
          
      

          
      Notes
      
          
      
            
      C D E F G A B
      octave from middle C
      
            
      c d e … b
      one octave up; c' two up
      
            
      C, B,,
      octaves down
      
            
      ^F _B =F ^^F __B
      sharp, flat, natural, doubles; they last to the end of the bar
      
          
      

          
      Lengths (× the L: unit)
      
          
      
            
      A2 A3 A4
      2×, 3× (dotted if L is a half), 4×
      
            
      A/ A/2 A// A3/2
      half, half, quarter, dotted
      
            
      A>B A<B
      broken rhythm: dotted + short, short + dotted
      
            
      z z2 Z Z4
      rest, longer rest, whole-bar rest, 4 bars' rest (x = invisible)
      
            
      AB c
      notes written together are beamed; a space breaks the beam
      
          
      

          
      Groups
      
          
      
            
      (3ABC
      triplet: 3 notes in the time of 2
      
            
      (3:2:2A2B
      2 notes in a triplet: exact 2:1 swing
      
            
      A-A (ABC)
      tie; slur
      
            
      [CEG]2
      stacked chord (length after the bracket)
      
            
      {g}A {/g}A
      grace note; acciaccatura
      
          
      

          
      Bars and repeats
      
          
      
            
      | || |] [|
      bar, double, final, thick-thin
      
            
      |: :| ::
      start repeat, end repeat, both
      
            
      |1 … :|2 … |]
      first and second endings ([1 [2 also work)
      
          
      

          
      Text over the music
      
          
      
            
      "Am7"A2 "G/B"B2
      chord symbols (also played by the player)
      
            
      "^text" "_text"
      annotation above / below the next note
      
            
      !p! !mf! !f! !ff!
      dynamics
      
            
      !crescendo(! … !crescendo)!
      hairpin (!diminuendo(! likewise)
      
            
      .A ~A !trill!A !fermata!A !accent!A
      staccato, roll, trill, fermata, accent
      
            
      !segno! !coda! "^D.C." "^Fine"
      navigation marks
      
          
      

          
      Lyrics
      
          
      A w: line under a line of music, one syllable per note:
      
          
      GA Bc d2 d2 |
w: Twin-kle twin-kle lit-tle star
      
          
      
            
      - _ * | ~
      split a word, hold a syllable, skip a note, jump to the next bar, join words on one note
      
          
      

          
      Layout and more
      
          
      
            
      new line
      a new line of music; a blank line ends the tune
      
            
      % text
      comment
      
            
      [K:D] [M:3/4]
      change key or time mid-tune
      
            
      V:1 … V:2 clef=bass
      several voices / staves
      
            
      %%MIDI program 73
      playback instrument (General MIDI number, 0 = piano)
